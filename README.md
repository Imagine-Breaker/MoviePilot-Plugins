# MoviePilot 自定义插件库

本项目为适用于 MoviePilot / MoviePilot-Neo 的第三方独立插件仓库。由 Antigravity 自动化运维与深度优化。

---

## 📦 插件列表

| 插件名称 | 插件 ID | 当前版本 | 说明 |
| :--- | :--- | :--- | :--- |
| **Bangumi追番伴侣** | `BangumiCompanion` | `1.0.0` | Bangumi 官方直连：想看/在看候选审核、MP 订阅反向同步在看、高精准 TV 动画防误识。 |

---

## 🚀 安装方法（网络导入）

1. 进入 **MoviePilot 后台** -> **插件** -> **网络导入**；
2. 输入本仓库地址：
   ```text
   https://github.com/Imagine-Breaker/MoviePilot-Plugins
   ```
3. 点击 **导入/安装** 即可完成加载。
